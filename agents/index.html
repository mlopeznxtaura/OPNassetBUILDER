What this is

OPNassetBUILDER (formerly GameForge) is a two-stage asset pipeline: Stage 1 design with live 3D preview, Stage 2 world placement. Shared state lives in a Cloudflare Durable Object; browsers show Live when synced.

MCP

POST JSON-RPC 2.0 to /mcp on this host. Methods: initialize, tools/list, tools/call.

curl -sS https://YOUR_HOST/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Local stdio proxy: mcp/stdio.js with GAMEFORGE_ORIGIN=https://YOUR_HOST.

Asset kinds

  • voxel — grid of colored cubes; paint_voxels or upsert_asset with cells. Optional seedStarter for name-based starter mesh.
  • sprite — 2D pixel grid; paint_sprite.
  • character — skinned glTF (female-hero, male-hero) or hosted character.src under /assets/*.gltf|.glb. UI shows the bound mesh URL; catalog name ≠ custom file unless src is set.
  • scan — optional reference photo on any asset; Scan 360 captures multiple frames locally; save stores frameCount + thumbnail, not full frame arrays in API state.

REST

  • GET /api/state — library + level + revision
  • POST /api/assets — upsert asset JSON body
  • POST /api/level/placements — add placement or {op:"remove",id}
  • POST /api/test — validation + collision probes
